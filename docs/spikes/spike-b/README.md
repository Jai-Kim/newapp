## Korean — native, not translationese

This is the part that could most easily have failed, and didn't.

- **Mimetic vocabulary throughout** — 톡톡, 반짝반짝, 축, 폭신한, 갸웃, 후.
  Sound/manner words are the signature of real Korean children's writing and the
  first thing missing from machine translation.
- **Consistent 요-form narration**, the right register for reading aloud to a
  5–6 year old.
- **`매실청` is the standout.** The English page says "plum syrup"; the Korean
  says 매실청 — a genuine Korean household staple, made exactly as described
  (청매실 한 켜, 설탕 한 켜, then months of waiting). It even uses 켜, the correct
  native counter for layers. The model chose an object that is culturally native
  in Korean *and* carries the page's "waiting" metaphor in English. That is
  composition, not translation.
- **`소리` (Sori)** — "sound", a natural Korean name and apt for a friend who
  arrives at the window at night.
- Idiomatic child narration: `기다림 끝에 이렇게 좋은 게 오기도 하는구나!` — the
  -는구나 realization ending is exactly how this beat is written in Korean.

Page alignment holds: every page's EN and KO narrate the same events.

## One finding to decide on: emotional shading drifts between languages

Native composition has a side effect. Page 2:

- **EN** — "It's **not fair**. I did everything."
- **KO** — "**이상해.** 나는 다 해 봤는데." ("That's **strange**. I tried everything, though.")

Same beat, same events, different feeling: injustice in English, puzzlement in
Korean. Both are natural in their own language, and the ADR only requires the
same *events* per page — so this is compliant. But in a dual-language book a
bilingual parent reads both, and the child hears two slightly different emotional
readings of the same moment.

Call it a feature (each language sounds native) or a bug (the versions should
match in tone as well as plot). Worth deciding before Week 2 — it is a
prompt-level fix either way.

## Wardrobe split works

Wardrobe varies per page while identity stays in `children.character_ref`:
ch1 raincoat → sleeves pushed up → raincoat off; ch2 mustard sweater →
rain-cloud pyjamas → pyjamas under a quilt. That is exactly the ADR-0001 §5
mechanism that Spike A's over-preservation finding called for — though note it is
proven only at the *text* layer. Whether the image model honours a per-page
wardrobe against a locked identity reference is **not yet tested**.

## For Spike C

$0.136 and 78s per 8-page chapter, text only. Combined with Spike A's
$0.039/image:

| Component | Cost | Time |
|---|---|---|
| Story text (8 pages, EN+KO) | $0.136 | 78s |
| Illustrations (8 pages) | $0.312 | ~70s sequential |
| **Total per chapter** | **~$0.45** | **~2.5 min** |

Images are ~70% of marginal cost, so bilingual text is close to free in
comparison — the ADR's "text roughly doubles, negligible next to images" holds.
Illustrations parallelise; the text call does not.

## Reproducing

```bash
cd docs/spikes/spike-b
python3 run_ch1.py    # opens the lantern thread
python3 run_ch2.py    # separate process; continues it from DB canon only
```

`CHILD_ID` in `spike_b.py` points at the seeded test child (Mia, 5–6, `ko`).
Re-running appends chapters 3, 4, … rather than replacing; clear the tables first
for a clean run.
